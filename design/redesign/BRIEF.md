# 枫琴教务中心 · 第三期界面重做 · 设计规范（给设计代理）

目标：把「学员、课表、线索、老师、设置」五个员工端页面，按已完成的新界面（今天、待办、财务概览、老师端、学员端）统一重做。本期只出**静态设计稿**给用户确认，不改产品代码。

## 参照（必须先看）
- 截图：`design/redesign/ref/ref-today-desk.png`（最完整的标杆）、`ref-todo-desk.png`、`ref-finance-desk.png`、`ref-today-phone.png`、`ref-todo-phone.png`；现状对比：`ref-students-current-desk.png`、`ref-students-current-phone.png`。
- 样式源码：`src/tenant/fq.css`（外壳、变量）、`src/tenant/fq-today.css`、`src/tenant/fq-finance.css`。只读需要的片段，不要整份通读。

## 视觉语言（从现有新页面提取）
- 颜色变量（fq.css）：`--fq-ink #2a1f3e`（主色/深紫）、`--fq-violet #6a35b8`、`--fq-violet-soft #eee6f7`、`--fq-plum #8e2f8c`、`--fq-amber #f6a54a`、`--fq-red #b4301f`、`--fq-paper #f4efe8`（底）、`--fq-card` 半透明奶白卡片 + `--fq-glass` 毛玻璃、`--fq-line`、`--fq-sub #655c72`、`--fq-faint`、`--fq-ribbon` 紫→红→橙渐变细条、`--fq-shadow`。
- 字体：中文 `--fq-sans`；英文副标题与大数字用 `--fq-serif` 斜体（页名后 "Today / Students"，统计卡数字）。
- 组件：
  - 统计卡（今天页顶部四张）：小标题 + 右上圆角方形图标底 + 衬线大数字 + 一行说明；告警数字用红色。
  - 面板：奶白圆角卡（约 16px 圆角）、标题 + 副说明 + 右上动作按钮（描边/浅紫/深色实心三级）。
  - 列表行：左侧状态点/头像字、主文字粗体 + 次文字灰、右侧彩色药丸标签（逾期红、线索紫、续费橙、收款绿）。
  - 时间线（今日课程）：时间 + 圆点竖线 + 卡片；进行中用深紫实心卡。
  - 深紫信息卡（This week）：深色底 + 衬线斜体英文标题 + 白色大数字。
  - 按钮：深紫实心主按钮、描边次按钮、浅紫幽灵按钮；药丸筛选。
- 手机（≤760px）：顶部深紫大标题区（见老师端/学员端截图风格）或标准顶栏；单列卡片；底部 tab 栏；列表→详情为整页切换；主要操作放底部固定按钮或卡片内。

## 产出要求
1. **先清点功能**：读现有实现（每个代理的任务里给了入口文件），列出这一页现有的全部功能、筛选、操作、抽屉/弹窗、权限差异。**设计不能丢功能**；确需合并、移动或建议删除的，单独列出理由，交给用户决定。
2. **设计稿**：在 `design/redesign/<页面>/` 下，复制 `design/redesign/_shared/template-desk.html` 与 `template-phone.html`（真实外壳与真实 CSS，内容区是 `<!--CONTENT-->` 占位），把占位替换成设计内容；页面头部 `header.v-head` 里的页名改成对应页（中文 + 英文斜体），侧栏高亮对应项。新增样式写在同目录 `mock.css`（只用上述变量，类名前缀 `fq-`+页面缩写，例如 `fq-st-` 学员），在模板 `<head>` 末尾引入。使用逼真的中文示例数据（虚构人名，琴房、课程如钢琴 1 对 1、乐理与视唱练耳、声乐、音乐制作·作品集）。不写脚本，纯静态。
3. **截图**：用 Playwright（已预装，`require('playwright')`，chromium.launch() 无需参数）以 `file://` 打开，电脑 1280×800（整页截图 fullPage）与 iPhone 13（devices['iPhone 13']，fullPage）各截一张主视图；有详情/抽屉/弹窗的关键状态再各截 1–2 张（可在同目录另做 html 状态页）。PNG 放同目录，文件名 `<状态>-desk.png` / `<状态>-phone.png`。截完自己看一遍，修掉溢出、重叠、空白过多等问题。
4. **说明**：同目录 `README.md`，≤60 行：功能清单 → 在新设计中的位置（表格）；交互说明（点击什么出现什么）；与现状相比的主要变化；需要用户决定的问题（如有）；实现时可复用的现有函数/接口（只列名字）。
5. 只写 `design/redesign/<页面>/` 目录，不改 `src/`、`tests/`、`_shared/`、`ref/`，不提交 git。
