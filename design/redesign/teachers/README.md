# 老师 Teachers · 设计稿说明

文件：`main-desk`（名单 + 选中老师详情）、`main-phone`（名单）、`detail-phone`（老师详情整页）、`edit-desk`（编辑老师抽屉，含在职/离职）、`rates-desk`（第二分页“课酬标准”）。各有 `.html` 与 `.png`，样式在 `mock.css`（前缀 `fq-tc-`）。

## 功能清单 → 新位置
| 现有功能（v2p.js `teachersView` / `teacherDetail` / `ratesPage`） | 新设计中的位置 |
|---|---|
| 页头副标题：在职 / 离职 / 本周共几节 | 不变 |
| 分页：老师 ｜ 课酬标准 | 页头分页（电脑、手机都在页头） |
| 新建教师（settings.create，手机不显示） | 电脑工具行右侧主按钮；手机名单底部提示“请用电脑端” |
| 搜索（姓名、科目）+ 科目药丸筛选 | 名单卡顶部；手机横向滚动药丸 |
| 名单行：头像字、科目·全职/兼职、本周节数，离职排最后变灰 | 同；离职加“已离职”标签 |
| 详情头：姓名、在职/离职、科目、全职/兼职、不在对外课表图显示、手机 + 显示号码、教师账号状态 | 详情头卡（手机为深紫头卡） |
| 编辑资料 / 导出课表图 / 给他排课 / 更多（开通教师账号、删除教师） | 头卡按钮行；手机底部固定条（编辑资料、给他排课、⋯） |
| KPI：本周课、本月已上、负责学生、本月课酬 | 统计卡：本周课、**待点名（新拆出）**、本月已上、在读学员；课酬移到深紫卡 |
| 本月工资（finance/payroll：节数、金额、已付、确认状态） | 深紫「This month · 课酬」卡，加“去财务 · 课酬结算 →” |
| 本周课表（点一节看详情，已上/待点名/待上），“在课表里按教师查看” | 按天分组的课表卡，今天高亮，待点名红底 |
| 课酬标准（当前生效，链接全部课酬标准） | 右栏卡片 |
| 负责的学生（点开学员档案） | 「在读学员」头像字标签 |
| 编辑/新建表单（姓名、状态、用工、手机、科目、对外课表图、排序） | `edit-desk` 抽屉；状态、用工改为分段按钮，离职给出说明 |
| 课酬标准分页：搜索、当前生效/全部、按老师分组、修改、删除、新增 | `rates-desk`，两列卡片，内容不变 |
| 权限：teacher_pay、students、schedule、accounts.reveal_phone 等 | 无权限时隐藏对应卡片 / 按钮，规则不变 |

## 交互
- 电脑：点名单行 → 右侧换成该老师详情（不跳页）。手机：点行 → 整页详情，“‹ 老师”返回。
- 点“编辑资料” → 右侧抽屉；状态切到“已离职”时显示黄色说明。
- 点课表里的一节课 → 打开原课程详情；点学员 → 学员档案；点待点名卡 → 点名。

## 与现状相比的主要变化
1. 待点名单独成卡（红色），课酬从 KPI 挪到深紫卡并显示已付 / 待付。
2. 本周课表按天分组。
3. 离职说明写在表单里，删除仍在“更多”。

## 需要用户决定
- 手机端是否也允许新建老师（现在电脑才能建）。
- “待付”= 本月课酬 − 已付，是前端算的；如果财务口径不同，请告诉我们。
