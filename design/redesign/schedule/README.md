# 课表 Schedule · 设计稿（第三期）

页面：`week.html` 周视图（手机为按天分组的周列表）· `day.html` 日视图（手机主视图）· `lesson.html` 课程详情 / 点名抽屉 · `new.html` 新建课程（点空白格子）· `fixed.html` 固定排课。截图为同名 `-desk.png` / `-phone.png`；样式在 `mock.css`（前缀 `fq-sc-`，复用今天页的 `.fq-card/.fq-stat/.fq-tl/.fq-lc/.fq-pill/.fq-btn`）。老师着色新增 6 组浅色（t1–t6），只在课表中使用。

## 交互
- 点课程卡片：电脑打开右侧详情抽屉；手机整页切换到详情页，顶部「‹ 课表」返回。
- 点空白格子或「在这里排课」：打开新建课程抽屉，时间已填好，网格里显示虚线占位块；改动任意字段后半秒内重新预查冲突。
- 点提示条上的「定位到这节」：滚动到冲突课程并高亮；「去调整」打开那节课的编辑表单。
- 点老师标签或手机上的老师筛选：只显示该老师的课程；统计卡的链接分别跳到待办（点名 / 补课）或冲突所在的课程。

## 与现状相比的主要变化
周视图上方加 4 张统计卡；默认按老师着色（原来按课程类别）；冲突汇总到页面顶部；今天一列有浅紫底色和 11:40 当前时间线。日视图沿用今天页的时间线，并显示空档。
