## 交互
- 电脑：点名单行 → 只换右侧详情；点页签 → 只换页签内容；筛选/搜索只刷新名单。
- 手机：点名单行 → 整页进入详情；「‹ 学员」返回；右上 ✎ 编辑档案、⋯ 打开与电脑「更多」相同的动作表。
- 页签在手机为横向滚动药丸，无「概况」（数字已在英雄卡里）。
- 抽屉：保存后关闭并刷新名单与计数；取消/✕ 关闭。

## 主要变化
1. 统计卡、时间线、深紫卡与今天页统一；余额用衬线数字并按状态着色。
2. 手机详情补回「更多」动作（现状手机端无法开通账号、改状态、删除），四个数字全部显示。
3. 课时包从宽表改为卡片行，次要操作收进「⋯」；流水默认显示最近 3 条。
4. 表单分组「家长端与 AI」改名「学员端与 AI」（决定 7：只保留学员账号）。
