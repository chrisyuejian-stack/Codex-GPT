学员Students

电脑：左边名单（筛选药丸：在读 / 已用完 / 快用完 / 全部）+ 右边详情（头部资料与动作、四张数字卡、页签）。手机：名单页 → 整页详情，右上「⋯」放开通账号、改状态、删除。

主要变化

  • 手机详情补回「⋯」动作组（开通账号、改状态、删除），四个数字全部显示。
  • 上课记录、跟进、学习阶段、曲目 / 作品四个页签沿用现有内容，只换卡片外观。

课表Schedule

顶部页签：周课表 / 按学员 / 固定排课 / 班级。周视图按老师（或教室、课程）着色，顶部四张数字卡，冲突单独红条提示并可定位；日视图沿用今天页时间线，右侧是老师和琴房占用条。点空白格子直接新建课程，实时检查冲突。

主要变化

  • 「按学员」「班级」两个页签沿用原结构，换新卡片样式。
  • 示例数据里周六 9 节只是为了展示效果。

线索Leads

电脑：统计卡 + 三列看板（新咨询 / 跟进中 / 已试听），已转正和已流失合成右侧一条窄列，可在看板和列表之间切换。点卡片打开详情抽屉，直接在里面记录回访。手机：按「今天要回访 / 之后」分组的列表，每行带拨打和记录回访按钮。

主要变化

  • 待办里的「记录回访」表单搬进线索详情，待办入口仍可直接打开它。
  • 新增按来源筛选。

老师Teachers

电脑：左边名单 + 右边所选老师详情。待点名单独一张红色卡，本月课酬放进深紫卡，课表按天分组。编辑抽屉里设置在职 / 离职，课酬标准单独一个页签。

主要变化

  • 本月课酬从统计卡挪进深紫卡，统计卡改为显示待点名。

设置Settings

电脑：左侧分区导航，分为总览、账号与权限、机构与品牌、课程与教室、教务规则、AI 设置、数据与备份、操作记录。总览页有统计卡、6 张分组卡和最近改动。手机：分组列表 → 整页二级页。

主要变化

  • 教务规则、AI 设置、数据与备份、操作记录四个分区没有单独出稿，布局写在说明里；数据与备份沿用已上线的新页面。
