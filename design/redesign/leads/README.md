# 线索 Leads · 设计稿说明

文件：`main-desk` / `main-phone`（主视图），`detail-desk`（线索详情抽屉 + 记录回访），`detail-phone`（手机详情整页），`followup-phone`（手机记录回访底部弹层）。各有 `.html` 与 `.png`，样式在 `mock.css`（前缀 `fq-ld-`）。

## 交互
- 点卡片 → 右侧抽屉（电脑）/ 整页详情（手机，左上“‹ 线索”返回）。
- 记录回访：选结果 → “有意向，约试听”换成试听时间并改阶段为已试听；“再跟进 / 没接通”填下次回访；“暂不考虑”标记流失。保存后在备注最上面加一行，时间线随之更新。
- 来源药丸与搜索只在前端过滤当前名单；手机用阶段药丸代替看板。

## 与现状相比的主要变化
1. 新增**来源筛选药丸 + 搜索**（纯前端过滤）。
2. 「已转正 / 已流失」合并为右侧窄列，流失默认只显示 2 条。
3. 卡片显示最近一次回访摘要（备注第一行）。
4. 备注按“MM-DD 回访：…”逐行解析成**回访记录时间线**；解析不了的行原样显示。
5. 手机端改为按“今天要回访 / 之后”分组的列表，每行带电话和记录回访按钮。

## 需要用户决定
- 来源目前是自由填写的文本，筛选药丸要按实际出现的值动态生成；是否改成固定选项（需要后端/设置配合）？
- 回访记录仍然存在 `note` 文本里；如果要可靠的历史（谁、何时），需要后端增加回访记录表。
- 手机端是否保留“看板”视图（目前只做了列表）。
