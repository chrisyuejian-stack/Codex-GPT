# 枫琴教务中心：单机构部署

本页与 `resources.template.json` 是当前资源、变量清单。`final/` 和 `upgrade-*` 是原艺界星途版本的历史交付材料，不用于新库部署；其中旧平台变量与路由已经失效。本次只更新部署材料，没有创建云端资源或部署。

部署域名：`edu.fantasmearts.com`。Pages 绑定 D1 `CHANNEL_DB`、私有 R2 `CHANNEL_MEDIA` / `CHANNEL_BACKUPS`；定时备份 Worker 绑定同一个 D1 和备份 R2。建议资源名称见 JSON 清单。测试环境使用独立库、桶、密钥。

Node.js 24+ 执行 `npm run build`，Pages 上传 `dist/`，定时 Worker 上传 `backup-dist/backup-worker.js`。新建空库依编号执行 `migrations/0001` 至 `0030`，包括安全审查迁移 `0002`。历史迁移不修改；0029 删除业务模块，0030 删除平台、机构外壳、家长和包库，保留业务 `tenant_id`。不导入旧数据。

Pages 配置：

| 名称 | 值 / 用途 |
| --- | --- |
| `APP_HOST` | `edu.fantasmearts.com` |
| `TENANT_ID` | 可选；首次初始化自动生成并持久化，或使用此固定值；以后配置须与记录一致 |
| `FIELD_KEY` | 32 字节随机值的 Base64，字段加密 |
| `BACKUP_KEY` | 32 字节随机值的 Base64，自动备份加密 |
| `HMAC_KEY`、`PW_PEPPER` | 各至少 32 字符的独立随机密钥 |
| `SETUP_KEY` | 至少 32 字符的一次性初始化密钥；成功后可删除 |
| `DEEPSEEK_API_KEY` | AI 提供方服务密钥；不返回客户端 |
| `AI_FAST_MODEL`、`AI_DEEP_MODEL` | 默认 `deepseek-chat` / `deepseek-reasoner` |
| `AI_FAST_DAILY_LIMIT`、`AI_DEEP_DAILY_LIMIT` | 默认 80 / 50，整数 0–1000000；主管内部设置可覆盖 |

初始化：向 `POST https://edu.fantasmearts.com/api/setup` 发送 JSON `{ "phone": "主管手机号", "password": "符合密码规则的密码", "name": "主管姓名" }`，请求头 `X-Setup-Key` 携带初始化密钥，`Origin` 为站点 origin。成功后写入固定实例和首个主管，接口自动关闭（后续 POST 404）；并发也只会成功一次。`GET /api/setup` 仅返回是否已初始化。之后所有角色从 `/login` 登录。新主管和其他账号由主管通过内部账号管理创建。

定时 Worker 配置 `FIELD_KEY` / `BACKUP_KEY`，值与 Pages 相同；可同步固定 `TENANT_ID`。Cron `0 19 * * *` 为北京时间每天 03:00 启动快照，`*/5 * * * *` 续传和清理；备份加密写入 R2，保留 30 天。未初始化时不启动备份。主管手动导出/整体恢复及列表下载将由任务 3 的新接口提供；原平台任务接口已删除。

无需额外的人机验证或身份代理。保留密码哈希、独立会话、字段加密和基础手机号/IP 登录限流。登录错误使用统一提示；员工会话绝对 12 小时、闲置 2 小时，教师/学员绝对 14 天。加密密钥在已有数据和备份存在期间保持不变。
