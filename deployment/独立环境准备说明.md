# 枫琴教务中心：单机构部署

本页与 `resources.template.json` 是当前资源、变量清单。`final/` 和 `upgrade-*` 是原艺界星途版本的历史交付材料，不用于新库部署；其中旧平台变量与路由已经失效。本次只更新部署材料，没有创建云端资源或部署。

部署域名：`edu.fantasmearts.com`。Pages 绑定 D1 `CHANNEL_DB`、私有 R2 `CHANNEL_MEDIA` / `CHANNEL_BACKUPS`；定时备份 Worker 绑定同一个 D1、媒体 R2 和备份 R2。建议资源名称见 JSON 清单。测试环境使用独立库、桶、密钥。

Node.js 24+ 执行 `npm run build`，Pages 上传 `dist/`，定时 Worker 上传 `backup-dist/backup-worker.js`。新建空库依编号执行 `migrations/0001` 至 `0031`，包括安全审查迁移 `0002`。历史迁移不修改；0029 删除业务模块，0030 删除平台、机构外壳、家长和包库，0031 新增备份预览与个人待办稍后记录，保留业务 `tenant_id`。不导入旧数据。

Pages 配置：

| 名称 | 值 / 用途 |
| --- | --- |
| `APP_HOST` | `edu.fantasmearts.com` |
| `TENANT_ID` | 可选；首次初始化自动生成并持久化，或使用此固定值；以后配置须与记录一致 |
| `FIELD_KEY` | 32 字节随机值的 Base64，字段加密 |
| `BACKUP_KEY` | 32 字节随机值的 Base64，自动备份加密 |
| `HMAC_KEY`、`PW_PEPPER` | 各至少 32 字符的独立随机密钥 |
| `SETUP_KEY` | 至少 32 字符的一次性初始化密钥；成功后可删除 |
| `DEEPSEEK_API_KEY` | AI 提供方服务密钥；不返回客户端 |
| `AI_FAST_MODEL`、`AI_DEEP_MODEL` | 默认 `deepseek-chat` / `deepseek-reasoner` |
| `AI_FAST_DAILY_LIMIT`、`AI_DEEP_DAILY_LIMIT` | 默认 80 / 50，整数 0–1000000；主管内部设置可覆盖 |

初始化：向 `POST https://edu.fantasmearts.com/api/setup` 发送 JSON `{ "phone": "主管手机号", "password": "符合密码规则的密码", "name": "主管姓名" }`，请求头 `X-Setup-Key` 携带初始化密钥，`Origin` 为站点 origin。成功后写入固定实例和首个主管，接口自动关闭（后续 POST 404）；并发也只会成功一次。`GET /api/setup` 仅返回是否已初始化。之后所有角色从 `/login` 登录。新主管和其他账号由主管通过内部账号管理创建。

定时 Worker 绑定同一套 `CHANNEL_DB`、`CHANNEL_MEDIA`、`CHANNEL_BACKUPS`，配置 `FIELD_KEY` / `BACKUP_KEY` / `HMAC_KEY` / `PW_PEPPER`，四项值均与 Pages 相同；可同步固定 `TENANT_ID`。Cron `0 19 * * *` 为北京时间每天 03:00 启动快照，`*/5 * * * *` 续传和清理；备份加密写入 R2，保留 30 天。未初始化时不启动备份。主管现在通过根 `/api/backups` 接口列表、导出、预览和整体恢复；原平台任务接口仍不存在。0031 之前的自动备份可保留用于人工排查，但不支持新版整体恢复。

无需额外的人机验证或身份代理。保留密码哈希、独立会话、字段加密和基础手机号/IP 登录限流。登录错误使用统一提示；员工会话绝对 12 小时、闲置 2 小时，教师/学员绝对 14 天。加密密钥在已有数据和备份存在期间保持不变。

## 全量备份与恢复（0031）

主管 `POST /api/backups/export` 发送 `{password}`，取得附件 `.fqbackup`。采用用户密码直接派生密钥：PBKDF2-SHA256 100000次（Cloudflare支持上限）、随机16字节盐，AES-256-GCM 与随机12字节IV及固定格式关联数据。密码须12–256字符，不保存密码。包含全部业务表、设置、账号与密码哈希、审计、个人稍后状态、图库元数据及有效图库对象；不含会话、限流和备份作业等运行时状态。服务端同时留一份 BACKUP_KEY 加密R2副本，主管可重新用密码下载。

上传预览支持 `multipart/form-data`（字段 `file`、`password`），或 JSON `{file:文件JSON对象或字符串,password}`。预览只校验/暂存，不覆盖业务；展示表行数、备份时间、版本与缺失媒体提示。暂存用 BACKUP_KEY 加密，只有创建预览的主管可在30分钟内确认。`POST /api/backups/restore/:id/confirm` 发送 `{confirm:true}` 执行整体覆盖，先完成恢复前R2备份，再同一事务覆盖业务/设置/账号/审计并清空所有会话。恢复后使用备份中的账号和密码重新登录。恢复前镜像会出现在备份列表，保留30天。

固定机构ID与 FIELD_KEY/HMAC_KEY/PW_PEPPER 必须与原备份一致，文件只带不可逆环境指纹，不包含任何环境Secret。BACKUP_KEY 只影响服务器R2副本/暂存；已下载的密码文件可在更换 BACKUP_KEY 后读取。旧格式或其他schema版本会明确拒绝，不做合并或旧数据迁移。图库现有对象若内容不同，恢复到新对象键，避免恢复失败时破坏当前图片；不删除无引用旧对象。若当前图片已丢失，恢复前镜像会记录其缺失，健康备份仍可修复；从带缺失声明的镜像恢复需额外 `allow_missing_media:true` 确认。

当前同步密码文件的明文（含图库）上限16MiB，上传上限24MiB；超限返回413并拒绝产生部分文件或执行覆盖。自动备份继续分页，超过同步下载上限的快照仍保存在R2。请在资源规划时考虑此上限；此版本不提供大文件分卷导出。数据库异常或安全备份失败不会覆盖当前数据；安全备份至事务提交之间检测到并发数据变更时返回409，重新确认会重新生成安全备份。

Worker每日北京时间03:00启动数据及图库快照，5分钟续传；缺图不会发布“完成”的自动备份，已有成功备份不受影响。每天与续传时同时清理30天前R2文件、过期预览及过期临时快照。迁移后部署新的Pages和备份Worker，并补齐上述媒体绑定及四项密钥，避免把不匹配的字段/密码环境写入自动备份指纹。
