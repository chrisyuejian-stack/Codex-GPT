# Antigravity 任务 3：端到端验收测试

先读 `AGENTS.md`（协作规则）。分支 `antigravity/e2e`，**等任务板任务 1（第三期界面重做）合并进 `main` 后**再从最新 `main` 开出。审查：Claude。开工前在 `docs/fengqin/任务板.md` 把任务 3 改为「进行中」。

## 目标
建立一套能在每个 PR 和每次上线前跑的端到端验收：真实浏览器，按角色走主要流程，确认页面没坏、流程能走通、关键界面与设计稿一致。

## 环境
- 仓库已有 `playwright.config.mjs` 与 `scripts/e2e/`（`npm run test:e2e`），先读懂再扩展，不要另起一套。
- 本地预览：`npm run build` 后 `TEST_BUNDLE=1 PREVIEW_PORT=<端口> npm run dev`，再 `PREVIEW_URL=http://localhost:<端口> node scripts/preview-seed.mjs` 写入虚构示例数据（主管 13911112222 / PreviewSecure9Z，学员 13800000008 / StudentPreview9Z）。老师、仅财务、教务账号用 `POST /api/accounts` 创建后改初始密码（做法见 `scripts/preview-seed.mjs`）。停服务按端口停，不要 `pkill -f scripts/dev.mjs`。
- 线上巡检（只读）：`https://edu.fantasmearts.com`，只做登录页与公开接口检查，**不要用真实账号在生产环境写数据**。

## 覆盖范围
1. **五个重做页面**（设计稿在 `design/redesign/<页面>/`）：学员、课表、线索、老师、设置。电脑 1280×800 与 iPhone 13 各跑一遍：打开主视图与各页签/抽屉；无 `pageerror`、无非预期 4xx/5xx；关键区块存在（以设计稿 README 列出的功能为准）。
2. **主要流程**（主管 / 教务 / 仅财务 / 老师 / 学员）：
   - 登录、登出、换人登录后离线数据清除；
   - 老师：今天页点名并提交点评；
   - 教务：排一节课、冲突提示、请假补课、待办处理（含「稍后」）；
   - 财务：登记缴费、补课时包价格、收款核对；
   - 线索：登记、记录回访、转为学员；
   - 学员：首页、课表、点评、课时与缴费（缴费开关关闭时不可见）；
   - 主管：数据备份导出与预览（不确认恢复也可）；
   - PWA：manifest 与 Service Worker 注册；老师/学员断网后能看到离线数据与提示条。
3. **视觉回归**：为五个重做页面与今天、待办建立基线截图（固定示例数据与时间，用 Playwright `page.clock` 固定时间），差异超过阈值时失败。
4. **冒烟子集**：挑 3 分钟内能跑完的子集，作为每个 PR 的必跑门槛，写进 `docs/qa/端到端.md`。

## 完成标准
- `npm run test:e2e` 全绿；冒烟子集单独可跑。
- 发现的产品问题：不直接改业务代码，提 Issue 或附失败的复现测试（标记为预期失败并写明 Issue），交给对应负责人。
- `docs/qa/端到端.md`：覆盖清单、怎么跑、怎么更新基线、已知问题。
- PR 描述列出新增文件；任务板更新状态。
