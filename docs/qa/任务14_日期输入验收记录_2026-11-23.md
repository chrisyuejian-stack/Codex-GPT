# 任务 #14：日期输入与日历组件修复验收记录（2026-11-23）

## 1. 问题复现与根因分析

线上用户在第三期上线后反馈两项日期控件核心问题：
1. **不能通过键盘直接输入日期**：
   - 旧版 `src/ui/components.js` 中的 `dateControl`（`UI.datePicker` / `UI.field({ type: "date" })`）渲染的是一个只读 `<button class="ui-picker-trigger">` 加 `<input type="hidden">`，导致用户无法在输入框内直接键入或粘贴日期。
   - 同时，部分页面（`fq-settings.js` 操作记录/AI 设置日期筛选、`fq-schedule.js` 固定排课学员开始/结束日期、`fq-leads.js` 行内回访日期、`v2pay.js` 登记/编辑缴费收款日期）仍直接使用原生 `<input type="date">`，未接入统一日期组件。
2. **日历弹层「上个月 / 下个月」按钮失灵**：
   - 旧版 `dateControl` 在 `root` 上注册了 `focusout` 监听：`setTimeout(() => { if (!root.contains(document.activeElement)) close(); }, 0)`。
   - 翻月按钮使用 `iconButton("上个月", ...)`（内部包装 `UI.button()` 异步处理器，点击瞬间设置 `b.disabled = true`），且 `render()` 直接执行 `popup.replaceChildren(head, week, grid)` 销毁被点击的按钮节点。
   - 当按钮被禁用或从 DOM 移除时，`document.activeElement` 立即回退到 `document.body`，触发 `focusout` 把日历弹层直接关闭（`popup.hidden = true`），或在移动端/抽屉（`<dialog>`）内吞掉点击事件。

---

## 2. 修复方案

### 2.1 统一日期组件 `src/ui/components.js` & `src/ui/components.css`
- **可手动输入 + 日历选择组合控件（`.ui-date-combo`）**：
  - 将只读触发按钮升级为真实可编辑 `<input type="text" class="ui-control ui-date-input" placeholder="YYYY-MM-DD" inputmode="numeric">` + 右侧日历图标按钮 `<button type="button" class="ui-picker-trigger ui-date-btn" aria-label="打开日历">`。
  - 新增并导出 `normalizeDateInput(raw, { defaultYear })` 与 `normalizeMonthInput(raw, { defaultYear })`，支持以下全部输入格式并在 `blur` / `Enter` 时自动归一为 `YYYY-MM-DD`：
    - `2026-11-22`、`2026-1-5`
    - `2026/11/22`、`2026.11.22`
    - `20261122`（8 位纯数字）
    - `2026年11月22日`
    - `11-22`、`11/22`、`1122`（默认补当前年份）
  - **非法日期与越界校验**：严格校验大小月与闰年（如 `2026-02-30`、`2025-02-29`、`2026-13-40`），非法或超出 `min` / `max` 时显示中文错误提示（`请填写有效日期，例如 YYYY-MM-DD`），设置 `aria-invalid="true"`，**保留用户已输入的原始文本不清空**；同时在 `src/tenant/app.js` 的 `submit(form)` 入口拦截含有 `aria-invalid="true"` 的日期输入并聚焦提示。
- **彻底修好「上个月 / 下个月」与年月快速切换**：
  - 使用独立同步导航按钮 `makeNavBtn`（`40×40px` 触控区，`.ui-calendar-nav`），在 `pointerdown` / `mousedown` / `click` 上执行 `e.preventDefault(); e.stopPropagation()`，并在 `root` 维护 `pointerInside` 守卫，翻月重绘后将焦点保持在日历弹层内，彻底杜绝因 DOM 重绘引起的 `focusout` 误关弹层。
  - 点击日历顶部「`YYYY年M月`」标题可展开**年份 + 1–12 月快速选择面板**（`.ui-calendar-ym`），支持跨年（如出生日期、入学日期）快速跳转。
  - 底部提供「今天」（以及 `allowEmpty` 时的「清除」）快捷按钮，支持 `ArrowLeft/Right/Up/Down`、`PageUp/PageDown`、`Home/End`、`Enter`、`Escape` 键盘导航。
- **全站调用点统一**：
  - 将 `src/tenant/fq-settings.js`（AI 设置、操作记录日期筛选）、`src/tenant/fq-schedule.js`（固定排课开始/结束日期）、`src/tenant/fq-leads.js`（行内写回访日期）、`src/tenant/v2pay.js`（登记/编辑缴费日期）中的原生 `<input type="date">` 全部统一替换为 `UI.datePicker`。
