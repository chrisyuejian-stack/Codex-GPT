# 按钮悬停与点击反馈统一规范验收（任务 #11，2026-11-23）

## 1. 盘点范围与统一规范

针对第三期重做页面中自定义按钮/药丸/页签/列表行缺少悬停动画与统一反馈的问题，在以下两处统一组件层落地（未逐页打补丁）：
- **通用组件层**（`src/ui/components.css`）：补全 `.ui-button--chip`、`.ui-button--link`、`.ui-page-tabs` 在 `@media (hover: hover)` 下的悬停过渡。
- **第三期主题统一层**（`src/tenant/fq.css`）：覆盖全部 `.fq-*` 可点击元素（主/次/幽灵按钮、筛选药丸、页签、侧栏导航、返回按钮、更多按钮、手机底栏、可点卡片/列表行）：
  1. **过渡**：`0.16s ease`（位移 `0.12s ease`）；
  2. **悬停（仅 `@media (hover: hover)`，避免触屏粘滞）**：边框高亮 `var(--fq-violet)` / 深色提亮 `brightness(1.08)` + 柔和阴影；行与页签增加 `rgba(106, 53, 184, 0.045–0.06)` 浅紫底；
  3. **按下（`:active:not(:disabled)`）**：`translateY(1px) scale(0.985)`；
  4. **键盘焦点（`:focus-visible`）**：`2px solid var(--fq-violet)` 外轮廓；
  5. **禁用 / 加载中**：`opacity: 0.48; cursor: not-allowed` / `[aria-busy="true"]` `cursor: progress; opacity: 0.72`；
  6. **减弱动态（`prefers-reduced-motion: reduce`）**：关闭过渡与位移动画。

## 2. 自动化验收

通过 [tests/e2e/ui-audit-and-hover.spec.mjs](../../tests/e2e/ui-audit-and-hover.spec.mjs) 实测：
- 筛选药丸、主按钮、列表行均具备非零过渡时长且 hover 后计算样式明确变化；
- `reducedMotion: "reduce"` 模式下 `transitionDuration` 正确归零（`0s`）。
